# 14 — Catatan keputusan produk dan operasi

Versi 2.4, 24 November 2026. Dokumen lama berjudul FIX v1.0 tidak lagi dianggap final seluruhnya. Keputusan di bawah berasal dari arahan pemilik produk dalam percakapan; hal yang belum diputuskan ditandai terbuka. Jangan menganggap usulan teknis sebagai persetujuan kebijakan kampus.

| K-25 | Terapkan proteksi DDoS berlapis (Nginx edge + aplikasi) dan tata kelola anti-bloat MySQL/RustFS yang sepenuhnya dapat dikonfigurasi via `infra/.env` agar home server bersama tetap lancar | Nginx menerapkan `set_real_ip_from` + `CF-Connecting-IP`, `limit_conn` 50/IP, `limit_req` berjenjang (auth, upload POST/PUT, API, `/health/ready`), `client_max_body_size` per rute, anti-Slowloris, & CSP; Backend menerapkan bounded LRU rate limiter, Argon2id semaphore maks 4, kuota (`USER_STORAGE_QUOTA_MB=100`, `MAX_REVISIONS_PER_ACHIEVEMENT=5`, `MAX_ACHIEVEMENTS_PER_PERIOD=30`, `MAX_SESSIONS_PER_USER=10`), penghapusan langsung objek RustFS saat ganti/hapus avatar & batal prestasi, Orphan GC (`> 24 jam`), retensi berkas tak aktif (`STORAGE_RETENTION_INACTIVE_DAYS=90`, `0`=nonaktif), batched MySQL TTL pruning (`AUDIT_RETENTION_DAYS=365`, `0`=selamanya), serta rotasi backup `--keep-days` (`BACKUP_RETENTION_DAYS=14`); seluruh ambang tetap dapat disesuaikan ketika kebijakan kampus `O-03`/`O-06` disahkan |

### K-26 — Rebranding Identitas Aplikasi ke UNIDA STUDENT CHAMPIONSHIP (USC)

Pemilik produk menetapkan penggantian nama aplikasi dari **TALENTA** menjadi **UNIDA STUDENT CHAMPIONSHIP (USC)** beserta pemasangan dua aset identitas resmi (**Emblem 3D Navy & Gold** dan **Wordmark `UNIDA STUDENT CHAMPIONSHIP`**) di seluruh permukaan aplikasi pada 24 November 2026:
- **Aset optimal**: Seluruh turunan (WebP + PNG fallback, multi-size `favicon.ico` 16–64 px, `apple-touch-icon.png`, ikon PWA/maskable + `site.webmanifest`, dan kartu Open Graph `1200 × 630`) digenerasi deterministik via `bun run brand:generate` dari dua berkas master di `docs/design/logo-usc-2026-11/sources/`.
- **Komposisi UI terpusat (`UscBrand.tsx`)**: Navbar desktop & footer memakai Emblem + Wordmark grafis transparan (varian tinta `#142432` pada latar terang; varian putih `#FFFFFF` + medalion terang untuk emblem pada latar gelap); mobile navbar & sidebar admin memakai Emblem + `USC`; halaman autentikasi menampilkan varian bertumpuk (*stacked*) atau emblem mandiri. Ikon aksi, navigasi, dan status tetap memakai Lucide React.
- **Batas kompatibilitas teknis**: Seluruh tampilan pengguna, metadata HTML/OG/manifest, email pemulihan kata sandi, nama file ekspor CSV (`rekap-prestasi-usc-*.csv`), log server, dan dokumen aktif beralih ke **UNIDA Student Championship (USC)**. Identifier internal & operasional (`DB_NAME=talenta_dev`/`talenta_test`, `S3_BUCKET`, cookie `talenta_session`, image GHCR `talenta-frontend`/`talenta-backend`, alias `@talenta/services`, serta nama berkas `PRD_TALENTA.md`) dipertahankan untuk mencegah pemutusan basis data, CI/CD, dan lingkungan existing.
- **Batas kebijakan**: Penggantian identitas aplikasi ini bukan pengesahan lambang atau kebijakan resmi kampus; keputusan institusional `O-05` tetap terbuka. Sumber master, spesifikasi teknis, dan bukti QA visual berada di `docs/design/logo-usc-2026-11/README.md`.
